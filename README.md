# Student-RegistrationForm
## Registration Form with Real-Time Validation

A simple and responsive registration form built using **HTML, CSS, and JavaScript**. It validates the Name, Email, and Password fields in real time, displays error messages for invalid inputs, and enables the Register button only when all fields are valid.

### Features
- Name field validation
- Email format validation
- Password validation (minimum 6 characters)
- Real-time error messages
- Submit button disabled until all fields are valid
- Clean and user-friendly interface

### Technologies Used
- HTML5
- CSS3
- JavaScript
